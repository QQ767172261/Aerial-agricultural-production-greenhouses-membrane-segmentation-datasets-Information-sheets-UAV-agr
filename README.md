## 数据集摘要
航拍农业生产大棚、地膜分割数据集包含17364张1250×1250分辨率无人机航拍图像，提供YOLO、VOC、COCO三种标注格式，共划分训练集14790张、验证集2093张、测试集481张；标注一共5个类别：谷仓、堆肥、堆肥（C类）、温室大棚、地膜。图像采集自真实农田航拍场景，包含多样地形、光照与作物状态，可用于实例/语义分割模型训练，适合基于低空遥感的农业地物自动化识别。

## 应用价值
1. **农业国土测绘**：自动识别温室大棚、地膜、谷仓等农业设施，快速统计设施农业面积，替代人工外业勘测，提升土地确权、农业普查效率。
2. **农田环境监管**：监测地膜覆盖范围，辅助农田白色污染溯源与治理；识别违规搭建农业大棚，支撑自然资源执法。
3. **智慧农业遥感监测**：定期航拍巡检，掌握大棚分布、堆肥存放情况，辅助农业生产规划、种植规模评估。
4. **低空遥感算法研究**：提供大规模带标注航拍农业样本，用于无人机图像分割模型训练、调优与算法对比，可支撑论文实验与工程落地。
